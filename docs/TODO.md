# CSWarfront 残タスク

最終更新: 2026-07-29（ブランチ `feature/mvp-core` 未マージ、Core 552/552 緑）

## 実装済み（主要なもの）

- 5勢力・関係マトリクス（敵対/中立/同盟/**宿敵**、Optionsで設定・宿敵は最優先攻撃）
- **KAIJU/Alien疑似勢力**：ゴジラ/エイリアンMOD導入時のみ関係設定行が出現。宿敵指定で距離無制限出撃
- 陸上7兵種 × Tier1-5／**海上（ミサイル駆逐艦・空母）／航空（戦闘機・爆撃機・自爆ドローン）**
- 兵種相性・命中率・ドメイン標的制限（対空が航空に2.5倍で本領発揮）・自爆ドローンは一撃消滅
- 基地4種（**陸軍/海軍/空軍/ミサイル**）を電力タブから配置、種別ごとに生産可能ドメインを制限
- **弾道ミサイル**：備蓄生産（¥250・24h・上限5）→ 右クリック指定で発射（AIは宿敵/遠距離基地へ自動発射）→ 対空ユニットが降下段階で迎撃 → 着弾で範囲ダメージ（設置猶予中の基地は無効）
- 研究によるTier解禁／AI編成バランス生産＋研究投資
- 道路A*（う回ジッタ）／遮蔽前進（前進保証）／建設後地表追従／海=水域制限・空=巡航高度120
- 範囲選択＋テンキーコマンド（NumLock無効時は数字キー代替）／**M&B風の指示先マーカー＋コマンドトースト**
- 発砲エフェクト・兵科別射撃音・撃破音（歩兵系はオミット）
- モデル割当（勢力別・Tier自動継承・**基地も勢力別**・4種アセット・複製適用・Options統合）
- 既定モデル15種（.obj自動生成、`tools/gen_models.py`）
- 戦闘域の道路封鎖（市民・車両が迂回）／ゴジラ・エイリアンとの交戦・撃退（`Defeat()` API連携済み、HP=Tier5基準: ゴジラ65000/エイリアン26000/装甲45）
- 空母の艦載機運用（随伴4機を自動建造: 戦闘機2/爆撃機1/自爆ドローン1、資金消費・Tier尊重）
- ミサイルは味方・同盟に誤爆しない（中立には巻き添えあり=意図的）
