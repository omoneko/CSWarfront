# CS:WARFRONT 経済・補給システム設計（Update 2）

日付: 2026-08-03
ステータス: 承認済み（ユーザー確認済み）
背景: Workshopコメント（CornMaruVT）の要望「全ユニットの弾薬上限・補給トラックによる再補給・
航空機の基地帰還再武装」への対応として作者がWorkshop返信で次回アップデートを約束。
ユーザーの発案でこれを3資源経済（人的資源・資金・生産力）の導入とセットで設計する。

## 0. 全体構成 — 2フェーズ実装

- **Phase A: 3資源経済**（人的資源・資金・生産力の産出と消費）
- **Phase B: 弾薬・補給ロジスティクス**（弾薬ゲージ・補給物資・補給トラック・帰還再武装）

Phase AはPhase Bの土台。セーブ形式は**v9を1回だけ**上げ、両フェーズの新フィールドを
まとめて追加する。旧セーブ（v8以前）は既定値（資源0＋初期付与、弾薬満タン）で読み込む。

## 1. 3資源の産出

経済tick（6時間ごと、既存のEconomyInterval）で、基地ごとに**半径1000m**内の建物を
スキャンし、ゾーン種別で3資源へ振り分ける（既存の「圏内発展度→資金」収入処理を置換）:

| ゾーン（CSのService種別） | 産出資源 |
|---|---|
| 住宅（Residential）の発展度 | 人的資源（Faction.Manpower、新設） |
| 商業・オフィス（Commercial/Office）の発展度 | 資金（Faction.Treasury、既存プールを流用） |
| 工業（Industrial）の発展度 | 生産力（Faction.Production、新設） |

- 発展度 = 建物レベル×規模（現行の収入計算と同じ考え方をService別に分けるだけ）
- Game層: BuildingManagerスキャン（simスレッド）。Coreは「Service別発展度の集計値」を
  受け取る純ロジックにして単体テスト可能に保つ
- **初期付与**: 新規開始時、各勢力へ人的資源・生産力にも初期値を与える
  （現行の開始資金200と同様。都市が未発達でも最初の部隊を編成できるようにする）

## 2. 資源の消費

| 消費先 | コスト |
|---|---|
| ユニット生産 | 人的資源 ＋ 生産力（不足分は資金で代替） |
| 補給トラックのスポーン | 人的資源 ＋ 生産力（同上） |
| 補給物資の自動生産 | 生産力（不足時は資金で代替） |
| 研究 | 資金（既存のまま） |
| 弾道ミサイル建造 | 資金（既存のまま） |

- 既存のUnitType.Costを兵科ごとの比率でManpowerCost/ProductionCostに分解する
  （歩兵系は人的資源重め、戦車・艦艇・航空は生産力重め）
- **生産力→資金の代替レート: 生産力1 ＝ 資金2**（調整可能な定数）。工業の無い都市でも
  割高ながら軍を維持できる
- AI（AiProductionPolicy）は3資源の残高を見て生産/研究を判断するよう拡張する

## 3. 弾薬ゲージ

- 全戦闘ユニットに `UnitInstance.Ammo`（0〜1のゲージ）を持たせる（v9で永続化）
- **射撃しているtickだけ**減少: `Ammo -= dt / AmmoCombatHours`（兵科別の連続射撃可能時間）
  - 目安: 歩兵12h / 戦車8h / 対空6h / 砲兵4h / 戦闘機・爆撃機は2〜3ソーティ相当
  - AmmoCombatHoursはUnitTypeに持たせ、unit-stats.xmlで調整可能にする
- **弾切れ（Ammo<=0）＝射撃停止のみ**。移動・拠点占領は可能。CombatStep/KamikazeStep/
  対空射撃/基地攻撃（BaseCombatStep）のダメージ適用を全てスキップする
- **自爆ドローンは弾薬対象外**（体当たりが本体、弾薬を消費しない）
- **Invader勢力は弾薬無限**（確定敵対のイベント敵。弾薬消費自体をスキップする。
  基地を占領して生産した場合も無限のまま＝管理不要）

## 4. 補給経路（2系統）

### 4.1 補給物資ストック（勢力共通プール）

- `Faction.SupplyStock`（新設、上限あり、v9で永続化）
- 経済tickごとに生産力（不足時は資金代替）から自動生産して備蓄する
- 基地圏内自動補給・補給トラックの積載はどちらもこのストックから引く。
  ストックが空なら補給は止まる（基地に居ても回復しない）

### 4.2 基地圏内自動補給

- 自勢力基地から**200m以内**の味方ユニットは、SupplyStockを消費しながらAmmoを回復する
  （回復速度: 25%/h、調整可能な定数）
- **空母（ユニット）も航空機に対してのみ補給点として扱う**（基地と同じ200m/25%/h、
  同じくSupplyStockを消費。空母運用の戦闘機/爆撃機が母艦で再武装できるようにするため）
- 航空機: 弾切れ→既存の帰還ロジック（ReturnHome）で航空基地/空母へ→基地圏内補給で
  再武装→満タンになったら自動で再出撃（「目標上空でホバリングし続ける」問題の解消）
- 艦艇: 海軍基地圏へ戻れば同じ仕組みで回復

### 4.3 補給トラック（新兵科）

- `UnitCategory.SupplyTruck`。**非武装・低HP**の通常ユニット扱い
  （攻撃されれば破壊される＝護衛の意味が生まれる。撃破時は積荷ごと失われる）
- **勢力あたり最大30台。戦闘ユニット150体の上限とは別枠**で数える
- 陸軍基地が自動維持: 台数が上限未満なら経済tickでスポーンを試みる
  （人的資源＋生産力を消費。資源不足なら補充されない）
- 挙動（完全自動・プレイヤー操作不要）:
  1. 基地でSupplyStockから物資を積載（積載容量あり）
  2. 道路沿い（既存Path/RoadGraph）に**弾薬残量が最も少ない味方陸上ユニット**へ向かう
  3. 到着（50m以内）で停車し、周囲の味方ユニットへ弾薬を転送する
  4. 積載が空になったら基地へ帰還して再積載
- 補給対象は**陸上ユニットのみ**（艦艇・航空機は基地圏内補給で賄う）
- Invaderは補給不要（弾薬無限）のためトラックを持たない

## 5. UI・可視化

- 勢力/基地パネルに3資源＋補給物資ストックの残高を表示
- ユニット情報パネルに弾薬残量を表示。弾切れユニットには小さな警告表示
- （MVP外: 資源産出の内訳表示、トラックの経路表示などは今回やらない）

## 6. テスト・互換性・その他

- Core純ロジック（Service別発展度→資源換算、コスト分解と資金代替、弾薬消費/停止、
  基地圏内回復、トラックの積載/配車/転送/帰還、航空機の再武装→再出撃、Invader無限弾）を
  すべてxunitでカバー。乱数不使用・決定的シミュレーションを維持する
- セーブ: WarStateSerializer v9（Faction.Manpower/Production/SupplyStock、UnitInstance.Ammo、
  トラックの積載状態）。v8以前は既定値で読み込み（資源は初期付与、Ammoは満タン）
- 500行制限: 新ステップは独立ファイル（EconomyStep拡張、SupplyStep、SupplyTruckStep等）
- リリース時: Workshop説明文・changenoteの更新、CornMaruVTへの返信

## 決定事項の経緯（Q&A）

1. 弾薬表現: **ゲージ方式**（発数方式は全兵科の戦闘を1発単位へ作り直す大改修になるため不採用）
2. コスト消費: **生産力優先・資金で代替**（選択式・全消費は不採用）
3. トラック入手: **基地の自動維持**（通常生産だと編成AI調整が必要で、生産忘れで兵站が止まるため不採用）
4. トラック上限: **30台/勢力、戦闘150体と別枠**
5. 基地圏内自動補給: **導入**（航空・海上・陸上を同一ルールで賄う）
6. Invader: **弾薬無限**（時間経過で襲来が無力化するのを防ぐ）
   → **2026-08-04改訂（実機フィードバック「侵攻部隊側が有利すぎる」）**: Invaderも弾薬制に変更。
   スポーン時の初期弾薬（満タン）のみを持ち、以後は**敵ユニットを撃破するたびに+25%回復**
   （現地調達、AmmoRules.InvaderAmmoPerKill）。基地圏内補給・補給トラックは一切受けられない
   （占領した基地の圏内でも回復しない）。撃破し続けられない波は弾切れで無力化し掃討できる。
